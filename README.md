##MAISON — Curated Objects E-Commerce Website
A luxury home goods e-commerce website built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no build tools.
##Overview
MAISON is a single-page e-commerce storefront for a curated home goods brand.
It showcases 12 products across four categories — Living, Ceramics, Textiles, and Lighting — with a refined editorial aesthetic inspired by luxury retail.
The entire site lives in a single index.html file with embedded CSS and JavaScript, making it trivial to deploy or hand off.
##Project Structure
ecommerce/
└── index.html        # Entire site — HTML, CSS, and JS in one file
└── README.md
All styles are in a <style> block in <head>. All JavaScript is in a <script> block before </body>.
