# MAISON — Curated Objects E-Commerce Website

A luxury home goods e-commerce website built with pure HTML, CSS, and vanilla JavaScript.  
No frameworks, no build tools.

---

## Overview

MAISON is a single-page e-commerce storefront for a curated home goods brand.

It showcases 12 products across four categories — Living, Ceramics, Textiles, and Lighting — with a refined editorial aesthetic inspired by luxury retail.
